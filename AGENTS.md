# AGENTS.md

This is a small Astro SEO micro-site.

## Commands

- npm run build
- npm run validate:content
- npm run validate:rendered
- npm run dev

## Rules

- Keep answers short and direct above the fold.
- Avoid unsupported manufacturer-specific claims.
- Every item needs an explicit `updated` date and source entry in `src/data/items.ts`; do not refresh review dates without reviewing the cited guidance.
- Treat rendered `undefined`, `null`, empty primary answers, and empty FAQ answers as release blockers.
- Domain purchase/connection is intentionally out of scope until Dylan chooses one.
